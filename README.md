# Employee Performance & Sales Analytics Dashboard

An interactive Employee Performance & Sales Analytics Dashboard built using **Microsoft Excel** and **Tableau**. This project transforms raw employee data into meaningful business insights through interactive visualizations and KPI dashboards.

---

## 📌 Project Overview

The objective of this project is to analyze employee performance, salary, compensation, and sales data to help HR professionals and management make data-driven decisions.

The dataset was first cleaned and analyzed in Microsoft Excel using formulas, Pivot Tables, and Slicers, then visualized in Tableau using an interactive dashboard.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Tableau Public

- Business Intelligence (BI)

## 📂 Dataset

The dataset contains employee-related information including:

- Employee ID
- Employee Name
- Department
- Location
- Salary (INR)
- Performance Rating
- Bonus Percentage
- Total Compensation
- Total Sales

---

## 📊 Dashboard Features

### KPI Cards
- Total Employees
- Total Sales
- Average Salary
- Average Performance Rating
- Average Compensation

### Visualizations
- Department-wise Average Salary (Bar Chart)
- Location-wise Total Sales (Bar Chart)
- Employee Distribution by Department (Pie Chart)
- Department-wise Total Sales (Treemap)
- Salary vs Total Sales (Scatter Plot)
- Top 10 Employees by Total Sales (Bar Chart)

### Interactive Filters
- Department
- Location

---

## 📈 Key Insights

- Identified departments with the highest average salary.
- Compared sales performance across different locations.
- Analyzed employee distribution across departments.
- Identified top-performing employees based on total sales.
- Explored the relationship between employee salary and sales performance.
